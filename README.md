# VPN Subscription Bot

Снимок проекта Telegram-бота и Mini App для управления подписками. В репозитории остались экранные компоненты, модели, миграции и интерфейсы сервисов.

- `miniapp/src/` содержит React-компоненты экранов тарифов, оплаты, профиля и подключения.
- `migrations/` содержит SQL-схему пользователей, серверов, тарифов, подписок и платежей.
- `internal/` содержит типы и сигнатуры серверной части. Методы оплаты, создания VPN-аккаунта и управления подпиской оставлены заглушками.

## Запуск

Go-модуль указывает версию 1.24. В публичном снимке отсутствует `cmd/bot`, на который ссылаются Makefile и Dockerfile. Сервер и Mini App в связке из этого репозитория не запускаются.
